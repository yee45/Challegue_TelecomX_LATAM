# 📊 TelecomX LATAM - Análisis de Evasión de Clientes (Churn)

## 📌 Descripción
Este proyecto realiza un análisis de **evasión de clientes (Churn)** en la empresa **TelecomX LATAM**, con el objetivo de identificar patrones de deserción y proponer estrategias que permitan **reducir la pérdida de clientes**.

El trabajo incluye:
- Importación y limpieza de datos.
- Análisis exploratorio (EDA).
- Visualización de patrones relevantes.
- Conclusiones y recomendaciones estratégicas.

---

## 📊 Análisis Exploratorio
Principales hallazgos del análisis:
- La tasa de churn es de **26.5%**.
- Los **contratos mensuales** y el método de pago con *electronic check* tienen mayor evasión.
- El servicio de **fibra óptica** presenta más deserción que DSL.
- Los clientes con **baja antigüedad (menos de 1 año)** son los más propensos a abandonar.

*(Ver gráficos y análisis detallados en el notebook.)*

---

## ✅ Conclusiones
- El churn es un desafío crítico que impacta en ingresos y estabilidad.  
- Se identificaron variables clave para explicar la evasión: tipo de contrato, método de pago, servicio de internet y antigüedad.  

---

## 🚀 Recomendaciones
1. Programas de **fidelización temprana** para clientes nuevos.  
2. Incentivar **contratos de mayor duración**.  
3. Mejorar la experiencia en **servicios de fibra óptica**.  
4. Promover métodos de pago más estables.  
5. Desarrollar **modelos predictivos de churn** con machine learning.
